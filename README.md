# SQL Learning Journey

A structured SQL practice repository where I work through SQLZoo-style exercises 
using real-world datasets instead of the original ones.

Each notebook covers a different SQL topic, contains the queries, and includes 
my own notes and observations written in Markdown.

## Why This Repo
I'm transitioning into a data analyst role with a focus on the mobile gaming industry. 
This repository documents my hands-on SQL learning process — not just solutions, 
but the reasoning and decisions behind them.

## Structure
Each folder corresponds to a SQL topic and contains:
- A Jupyter Notebook with queries and notes
- A README explaining the goal and outcome

## Tools
- Python, Pandas
- SQLite
- Jupyter Notebook
